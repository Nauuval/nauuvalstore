# ANALISIS LAYOUT NAUUVALSTORE

## Struktur Saat Ini:
1. Header/Nav
2. Hero Section
3. **Services/Layanan** ← INI YANG MAU DIPINDAH
4. Steps/Cara Pesan
5. Testimoni
6. Komunitas
7. Dukungan
8. Footer

## Masalah Yang Mungkin Terjadi:
- Section layanan mungkin terlalu panjang/berat di atas
- User harus scroll jauh untuk lihat info penting lain
- Pertama kali buka web langsung kena "jualan"
- Kurang ada "flow" yang natural

## Rekomendasi Layout Baru:

### Option 1: Pindah Layanan ke Bawah (Minimal)
1. Hero
2. Steps/Cara Pesan
3. Testimoni (bukti kepercayaan)
4. **Layanan** ← Dipindah ke sini
5. Komunitas
6. Dukungan
7. Footer

**Alasan:** User lihat dulu cara pesan + bukti testimoni, baru lihat layanan detail.

### Option 2: Gabungkan dengan Katalog (Recommended)
1. Hero
2. **KATALOG PRODUK** ← Link ke katalog.html (singkat, jelas)
3. Steps/Cara Pesan
4. Testimoni
5. Komunitas
6. Dukungan
7. Footer

**Alasan:** 
- Homepage lebih bersih, fokus ke informasi penting
- Detail layanan ada di katalog.html (sudah dibuat)
- User tidak overwhelmed dengan banyak info di 1 halaman
- Lebih modern, mengikuti tren webstore

### Option 3: Layout Card di Homepage (Simple)
1. Hero
2. 4 Card Kategori (singkat, link ke katalog)
3. Steps
4. Testimoni
5. Footer

**Alasan:**
- Homepage jadi "landing page" yang clean
- User klik card untuk lihat detail di katalog
- Tidak menumpuk, mudah dipahami

## Saran Saya:
Gunakan **Option 2** - Homepage fokus ke:
- Hero (branding)
- Cara Pesan (info penting)
- Testimoni (trust building)
- Link ke Katalog untuk detail layanan

Layanan detail sudah ada di katalog.html dengan filter kategori, stok live, dll.
